# 传奇打斗逻辑 — Seedance视觉翻译

> 传奇战斗≠现代ARPG。它的节奏是"一刀一刀算"，不是"一气呵成连招"。
> 本技能内置传奇世界观+职业体系+实战操作，一站式翻译成Seedance能理解的镜头语言。

## 零、传奇世界观速览

### 0.1 玛法大陆核心设定

传奇世界=玛法大陆。人类、半兽人、怪物三族对抗，远古魔神沉睡地下。

**创作情绪锚点**：
```
兄弟情 + 爆装备金光 + 沙巴克战场 + 慢练级苦行 + 高风险PK = 传奇
```

**不可缺失的传奇DNA**：
- 装备掉落必须有"金光"——装备自身悬浮发光旋转
- 屠龙刀是视觉图腾——宽刃黑色大刀，传奇符号
- 沙巴克=终极荣耀——城墙、皇宫、旗帜
- 红蓝双球UI是视觉烙印（视频中转化为药瓶+状态）
- "兄弟"二字贯穿一切——无兄弟不传奇

## 一、传奇战斗核心哲学

### 1.1 不是连招游戏，是博弈游戏

```
现代ARPG：闪避→轻击×3→重击→技能取消后摇→连击计数
传奇战斗：走位调整→等对手露出破绽→一刀刺杀→跑开→再找下一刀的机会
```

**视觉翻译**：不是写"一套连贯的连招"，而是写"一招→停顿→走位→再一招"。每刀之间有思考和预判的空间。

### 1.2 三慢一快的节奏铁律

| 阶段 | 节奏 | 视觉表现 |
|------|------|---------|
| 走位试探 | 慢 | 两人保持距离绕圈，目光锁定，脚步碎而稳 |
| 抓住破绽 | 快 | 一刀刺杀劈出，剑气隔空命中 |
| 重击终结 | 爆发 | 双烈火近身，刀身爆燃，一刀秒杀 |
| 战后留白 | 慢 | 收刀喘息，装备金光浮现 |

**铁律**：传奇战斗不能全程快节奏。快只在"出刀瞬间"。一刀之后必须回到慢节奏。

## 二、隔位刺杀→视觉翻译

### 2.1 什么是隔位刺杀

战士与目标之间**空出一个身位**（约一米），刀身发出剑光/剑气，隔空劈中目标。这不是"砍到身上"——是"剑气贯穿"。

### 2.2 视觉翻译规则

| 元素 | 写法 |
|------|------|
| 站位 | `秦牧距BOSS一米停下，双脚前后开立` |
| 出刀 | `右手战刀横斩——刀身未触及BOSS，橙红剑气从刀刃脱出贯穿BOSS躯干` |
| 命中 | `剑气穿透瞬间——BOSS身体后仰，暗红角质裂开一道横贯伤口的裂痕` |
| 视角 | 侧面拍——必须同时看到刀和目标的距离，展现"隔空"关系 |

**禁止写法**：
- ❌ `秦牧一刀砍在BOSS身上`（变成了近身平砍）
- ❌ `刀身嵌入BOSS肩膀`（隔位刺杀不接触）

**正确写法**：
- ✅ `秦牧距BOSS一米挥刀——橙红剑气从刀尖脱刃而出，隔空贯穿BOSS胸口`
- ✅ `两人之间空出一米——秦牧战刀横扫，剑气从刀刃延伸成弧光劈入`

### 2.3 隔位刺杀镜头模板

```
景别：MS侧面双人
角度：侧面平拍（同时看到秦牧和BOSS的距离）
镜头：固定
内容：秦牧画左，BOSS画右——两人相距一米。秦牧右脚前踏，右手战刀从右下向左上斜挑——刀身未触及BOSS，一道橙红剑气从刀尖脱刃而出，隔空劈中BOSS胸口。剑气贯穿瞬间——BOSS胸口暗红角质炸开一道横贯裂口，身体后仰半步
```

## 三、战士技能库→分镜视觉链

### 3.1 基础剑术（普攻）

- 视觉：刀身直接砍中，朴实无华的金属碰撞，无特效
- 景别：MS中景即可
- 不是主要表现对象——传奇不用普攻打伤害

### 3.2 攻杀剑术（19级·概率暴击）

- 视觉：刀身瞬间闪白光，命中时产生小型冲击波——比普攻亮、比刺杀弱
- 定位：过渡技能，不专门设计镜头
- 出现方式：穿插在刺杀镜头中，某一次出刀刀身额外闪白光

### 3.3 刺杀剑术（25级·核心输出）

- 来源：热血传奇官方技能
- 视觉：刀尖发出银白色半月形刀光，刀刀出光，攻击速度快，直线隔空贯穿
- 动作：人物面对目标→右手握刀→刀尖向前点出→银白色半月形刀光从刀尖脱刃飞出
- 光色：银白色/白色刀光，半月弧线轮廓
- 命中特效：目标身体出现裂口→后仰→白色光粒从裂口溢出
- 特点：隔位攻击无视防御、攻击速度快、无蓄力、无起手延迟
- 镜头公式：侧面中景拍→刀尖白光亮起→半月刀光飞出→隔空命中目标→目标后仰

### 3.4 半月弯刀（28级·群攻）

- 视觉：战刀从右向左横扫，刀身拉出180°弧形剑气——正前方扇形范围
- 命中：前方多个目标同时被剑气扫中后仰
- 镜头：正面拍秦牧→广角收进面前所有小怪
- 注意：PK时关掉半月，只打BOSS/群怪时用

### 3.5 野蛮冲撞（30级·突进控制）

- 视觉：战士身体前倾，肩甲在前，整个人化为一道残影直线冲出
- 距离：5格（游戏中≈5米，视觉中可写3-5米）
- 命中：撞到目标→目标被定住/倒退，战士停在目标身前
- **变向技巧（天花板操作）**：冲出去后立刻变向——冲→停→脚蹬地→往反方向跑一步→转身出刀
- 镜头：侧面跟拍冲撞过程，变向时快速横摇

### 3.6 烈火剑法（35级·爆发终结）

- 视觉（单烈火）：战士双手举刀过顶→刀身被橙红火焰吞没→全力下劈→命中瞬间火焰炸开
- 视觉（双烈火）：第一刀烈火劈下→火焰未散→第二刀烈火紧跟着劈在同一位置→两次爆炸叠加→白光吞没画面
- **双烈火是传奇战士的最高输出**：在0.5秒内连续劈出两刀烈火，秒杀满血目标
- 景别：CU特写刀身蓄力→MS全景劈落→CU特写命中面部的冲击光

### 3.7 开天斩（38级·高伤远程终结）

> 🔴 2026-07-31 导演纠正原版特效，替换旧版私服魔改描述

- 来源：热血传奇官方技能（开天斩）
- 🔴 **核心区分**：人物原地不动，只有手臂前劈发力——**和逐日（能量冲出去）、野蛮冲撞（人冲出去）是三个完全不同的位移逻辑**
- 视觉（原版官方特效）：
  - **形态**：多层重叠的弧形银色光刃，宽幅向前铺开的半月扇形——不是直线光束、不是从天垂直砸落的巨剑
  - 🚫 网上流传的"天上落下巨剑"属于私服二次修改补丁，非原版
  - **颜色**：蓝白/银白，剑身先浮现淡蓝白微光→脚下环形光晕→身前凝聚扇形剑气
- **动作序列（5秒完整版）**：
  1. **蓄力（0-1.2s）**：双脚分开低重心站稳，双手握剑向上举过头顶，剑身浮现淡蓝白微光，脚下生成一圈淡蓝环形光晕
  2. **凝能（1.2-2.5s）**：剑身能量向外扩张，身前凝聚多层重叠弧形银色光刃（半月扇形向前铺开）
  3. **释放（2.5-3.8s）**：手臂向前发力劈出——凝聚完成的扇形剑气整体向前平缓推送滑行，有厚度、范围宽
  4. **命中（3.8-5s）**：扇形剑气接触瞬间光刃炸开，银白碎片粒子向外迸发，魔物僵直后退，地面震荡扬尘
- 镜头：斜侧45°俯拍（默认机位）→ 蓄力和凝能用MS中景 → 释放时微仰拍收剑气厚度 → 命中切后背俯视角沉浸感
- 特点：伤害高于烈火，攻击距离更长，有冷却时间。群体伤害，前方扇形范围

**提示词落笔要点**：
- ✅ 写"手臂向前发力劈出"——有劈的动作，脚不动
- ✅ 写"多层重叠弧形银色光刃，宽幅半月扇形向前铺开"
- 🚫 不写"巨剑虚影""从天劈落""轰入地面"
- 🚫 不写人物前冲、位移

### 3.8 逐日剑法（47级·直线群体贯穿）

- 来源：热血传奇官方技能（逐日剑法）
- 视觉（核心画面·163.com玩家实测描述）：金色剑气凝聚成一个**手持利刃往前冲的人形光影（人形剑气）**，带着刺破虚空般的视觉压迫向前直线冲刺，金色拖尾拉满
- 颜色：金色（暖金底光，从剑尖向外渐变扩散）
- 人形细节：不是纯光柱、不是光球——是一个可辨认的**人形轮廓**，手持利刃姿态，向前冲刺姿态
- 动作序列：战士站稳→双手举刀→刀身前方金色剑气凝聚→金色人形脱刃而出→向前直线冲刺→贯穿路径上所有目标→被贯穿者身体穿透→金色拖尾粒子炸散
- 命中：直线群体贯穿，路径上所有目标依次中招，无视魔法盾
- 镜头：侧面中景拍蓄力凝聚→金色人形脱体冲出→正面广角收直线贯穿路径→慢镜收金色拖尾粒子消散

### 3.9 龙影剑法（48级·扇形群体穿刺）

- 来源：热血传奇私服高级技能（龙影剑法）
- 🔴 核心视觉：**四道银白剑气扇形散开，每道剑气轮廓内包裹一条银白龙影——四条龙影同步向前穿刺冲刺，千军万马之势**
- 龙影形态：不是纯剑气、不是光影——每道剑气内部可辨认出**龙形轮廓**（龙头在前，龙身蜿蜒向后延伸），边缘流动银白光雾
- 整体气势（bsmir.com描述）：**犹如千军万马向敌人攻去，令敌人落荒而逃**——四条龙影同步冲锋的群体压迫感
- 光色：冷银白色主光，龙影轮廓边缘泛微弱冷蓝光雾，拖尾为银色粒子光痕
- 动作序列：战士举刀过顶→向下劈砍→劈落瞬间身后拉出一道主银色剑光→剑尖分裂四道独立剑气→每道剑气内显出龙形轮廓→四条银白龙影呈扇形向前同步冲刺→击中炸开细碎银白粒子→收刀
- 动态：龙影飞出带拖尾光痕→"破空撕裂空气"质感→释放瞬间屏幕轻微震动
- 范围：扇形大范围群攻，覆盖角度约60-90°，群体伤害
- 镜头：侧面拍起手举刀→正面广角收四条龙影扇形飞出全貌→慢镜收龙形轮廓+光粒炸散

## 四、走位拉扯→镜头翻译

### 4.1 绕怪转圈刺杀

**视觉翻译**：
```
景别：FS全景跟拍
角度：微俯拍环绕
镜头：360°环绕跟拍
内容：秦牧双脚不停碎步移动——始终与BOSS保持一米距离。每跑两步右手战刀出手一次——橙红剑气从刀刃脱出贯穿BOSS。秦牧从BOSS正面绕到侧面→绕到背后→再绕回正面。全程不在任何一个位置停留超过一秒。BOSS在圆心位置不断转身试图锁定秦牧，每次转身秦牧已换到新位置
```

### 4.2 打方向（不追人）

**视觉翻译**：不是"冲向敌人砍一刀"——是"目光锁定、脚步游走、突然停住、一刀刺出"。停住的位置恰好是隔位距离。

### 4.3 双战士交叉刺杀

**视觉翻译**：
```
镜头1（全景建立空间）：
秦牧画左，晚晴画右，两人相距5米面对面站立。BOSS站在两人之间偏画左位置——正面向秦牧，背对晚晴

镜头2（秦牧正面）：
秦牧右手战刀前刺——橙红剑气贯穿BOSS胸口。BOSS嘶吼转身面向秦牧

镜头3（切晚晴背面）：
BOSS背对晚晴——晚晴右手战刀出手。青白剑气从背后贯穿BOSS。BOSS再次转身面向晚晴

镜头4（侧面双人）：
两人交替出刀——BOSS在两人之间反复转身，每次转身刚确定方向就被另一侧的剑气贯穿。暗紫能量从全身裂口不断泄漏
```

## 四B、传奇2.5D斜侧俯拍→Seedance机位翻译

### 4B.1 什么是传奇2.5D视角

传奇经典视角 = **等角投影（Isometric Projection）**，约35°俯角 + 斜侧方向。

画面特征：
- 地面像菱形展开，能同时看到顶面+两个侧面
- 纵深和水平同时展开，不像平拍前后遮挡
- 近大远小透视弱化，距离关系清晰
- 人物8方向移动，每个方向都清晰可辨

### 4B.2 翻译成Seedance镜头语言

```
角度：斜侧俯拍，机位侧上方约35°
```

**这个视角为什么适合传奇打斗：**
- **地面信息全开**：隔位刺杀的距离感（一米空位）天然成立
- **走位轨迹可见**：碎步绕圈的弧线在地面上一目了然
- **群战信息量最大**：多打多时谁在哪不用切镜头，一个斜侧俯拍全景全装下
- **传奇味**：观众一看这个角度就知道是传奇——不是电影平拍，不是全俯上帝视角

### 4B.3 🔴 三种常用机位 + 技能适配（2026-07-31 导演指定）

| 机位 | 角度写法 | 适配技能 | 效果 |
|------|---------|---------|------|
| **斜侧45°俯拍**（默认） | `斜侧俯拍，机位侧上方约45°` | 烈火剑法、开天斩、逐日剑法、刺杀剑术 | 通用走位+出招，地面信息全开 |
| **纯侧面** | `侧面平拍` | 野蛮冲撞、冲锋 | 展现长位移轨迹，可观位移距离 |
| **后背俯视角** | `后背俯拍，机位在人物后上方` | 大招爆发（双烈火/龙影/群体终结） | 沉浸式观感，跟人物一同面对爆发 |

**切换规则**：
- 走位对峙 → 斜侧45°俯拍（默认）
- 长位移突进 → 切纯侧面（跟拍冲撞全程）
- 终结爆发 → 切后背俯视角（沉浸大招）
- 三机位可在一段内切换，不用锁死一个角度

### 4B.4 使用场景

| 场景 | 机位 | 理由 |
|------|------|------|
| 走位对峙/绕圈 | 斜侧45°俯拍 | 展现绕圈轨迹和距离关系 |
| 刺杀/烈火/逐日出刀 | 斜侧45°俯拍 | 地面信息全开，隔位距离可见 |
| 野蛮冲撞/冲锋 | 纯侧面平拍 | 展现位移距离和速度感 |
| 一前一后拉扯换位 | 斜侧45°俯拍 | 纵深位移是这个角度最强的表现力 |
| 双烈火终结 | 后背俯视角 | 沉浸式，跟人物一同面对爆炸 |
| 龙影/大招爆发 | 后背俯视角 | 扇形群攻从背后看气势最满 |
| 战后留白 | 缓推中景 | 切回平拍/中景，情绪收束 |

## 四C、一前一后纵深拉扯战术

### 4C.1 站位逻辑

```
秦（画左前景，距BOSS一米）← BOSS（居中）→ 晚晴（画右上方后景，距BOSS三米）
```

斜侧35°俯拍下，三个人在地面上构成一条斜线——不重叠，纵深关系全开。

### 4C.2 战术节奏

```
秦先手（近身隔位）→ 2-3刀刺杀输出
  ↓
秦碎步后退，从前景退向远处，拉开到三米
  ↓
BOSS转身追秦（朝画左下移动）
  ↓
晚晴从右上方后景斜插切入 → 到BOSS侧面隔位
  ↓
晚晴输出2-3刀
  ↓
秦绕回 → 交叉换位 → 回到初始站位
```

### 4C.3 为什么比纯绕圈好

绕圈是水平位移，一前一后有纵深位移——观众看到的不只是左右绕，还有前后拉扯。
斜侧俯拍这个角度，人物从后景冲到前景的变化幅度比侧面平拍大得多，画面张力更强。

### 4C.4 关键镜头

晚晴从画右上方切入那一下——机位不动，人物在画面里从远景区斜插到中景区，这个纵深移动本身就是画面张力。
写法：`晚晴从右上方后景斜插切入到中景隔位停住`

## 五、传奇战斗节奏→分镜设计

### 5.1 15秒传奇打斗节奏模板

```
[0-3秒]  走位对峙（慢）
         景别：FS双人全景 | 镜头：环绕/固定
         内容：两人绕圈走位，目光锁定，刀身在身侧随步伐轻晃
         气氛：紧绷的安静，只有脚步声和风声

[3-5秒]  第一刀试探（快）
         景别：MS侧面 | 镜头：固定→微推
         内容：一刀刺杀试探，剑气擦过目标身侧未命中——试探破绽
         转场：出刀瞬间画面微震

[5-8秒]  连刺压制（快→更快）
         景别：MS→CU交替 | 镜头：跟拍+急摇
         内容：连续2-3次刺杀命中，目标不断后仰，裂口增多
         转场：每次命中画面震动

[8-11秒] 破绽→近身（爆发前摇）
         景别：MS→CU推 | 镜头：急推
         内容：目标露出大破绽——战士脚蹬地加速前冲。野蛮冲撞突进到目标身前
         转场：冲撞瞬间镜头剧烈晃动

[11-14秒] 双烈火终结（爆发）
         景别：CU→LS广角 | 镜头：仰拍→急拉
         内容：双手举刀过顶→刀身火焰爆燃冲天→第一刀烈火劈下→第二刀紧随——两刀叠加爆炸，白光吞没画面
         转场：爆炸白光渐弱→暗场

[14-15秒] 战后留白（慢→定格）
         景别：MS→静帧 | 镜头：缓推→定格
         内容：白光消散→BOSS身体化作白色粒子升空→装备金光浮现
         转场：画面定格在战士喘息的侧影+漫天白色粒子
```

### 5.2 传奇战斗的独有节奏感

| 节奏特征 | 怎么说 | 怎么做 |
|---------|--------|--------|
| 慢 | 走位试探占据大半时间 | 镜头给够走位空间，不急着出刀 |
| 炸 | 出刀瞬间爆发 | 出刀=画面震动+光效爆发，一刀一个冲击点 |
| 止 | 命中后停顿 | 一刀命中→0.5秒停顿→走一步→再一刀，不是连续砍 |
| 空 | 收刀后的安静 | 装备掉落金光浮现时，画面回到安静——这是传奇最爽的时刻 |

## 六、传奇独有视觉符号

### 6.1 装备掉落金光

传奇最标志性的视觉——不是现代游戏的光柱，是**装备自己悬浮发光**。

```
一把暗金纹路长剑悬浮在金色光芒中缓缓旋转，剑身流动暗金纹路
一双靴子在紫色光团中自转，靴面泛幽紫光泽
金币如暴雨坠落，在地面铺成金色地毯直径十米
```

**铁律**：装备是自身发光的，不是地面射光柱。每件装备单独一句描述。

### 6.2 药瓶视觉（不用血条）

传奇没有血条——用红蓝药瓶替代血量状态：
- 战斗中秦牧掏红药瓶仰头灌下——状态在恢复
- 药瓶打碎在嘴角——残血挣扎
- 最后一瓶红药被拍飞——弹尽粮绝

### 6.3 绿色数字（回避）

传奇打怪头上飘绿色伤害数字。视频里不用写——会破坏写实感。用"伤害反馈"替代：
- ✅ 剑气贯穿瞬间BOSS身体后仰，裂口加深→表示命中
- ❌ 不要写"绿色数字飘出""伤害数字跳出"

### 6.4 传奇战士体型语言

传奇战士不是花哨的剑客——是**厚重的、扎实的、一刀一刀砸的**：
- 双手握刀（不是单手耍帅）
- 每次出刀前都有重心下沉的蓄力
- 步伐是碎步侧移，不是跳跃翻滚
- 肩甲厚重，转身时肩甲随身体自然转动

### 6.5 经典听觉记忆（音效参考）

视频提示词中不写音效，但设计分镜时心中有数：
- 比奇城BGM → 悠扬、温暖、回家的感觉
- 盟重BGM → 苍凉、史诗感
- 沙巴克BGM → 激昂、热血、战鼓
- 爆装备 → "叮"一声清脆 + 金光特效
- 升级 → "轰"一声雷鸣 + 光柱

### 6.6 🔴 刀芒规格（2026-07-31 导演指定·永久规则）

**每一刀拉出长条形金银色刀芒，持续多层运动拖影。**

| 技能 | 刀芒颜色 | 形态 |
|------|---------|------|
| 刺杀剑术 | 银白色 | 长条形，半月弧线轮廓 |
| 攻杀剑术 | 白光 | 刀身闪白光，短促 |
| 烈火剑法 | 橙红→金色 | 刀身被火焰吞没，劈落拉出火尾拖影 |
| 开天斩 | 蓝白/银白 | 多层重叠弧形光刃，半月扇形向前铺开 |
| 逐日剑法 | 金色 | 金色人形剑气拖尾 |
| 龙影剑法 | 冷银白 | 龙形轮廓拖银白粒子光痕 |

**提示词写法**：
```
刀尖拉出银白长条形刀芒，多层运动拖影沿刀锋轨迹展开
```

- ✅ 长条形刀芒（不是点状光、不是光球）
- ✅ 多层拖影叠加（不是一道光闪过）
- ✅ 金银色系（刺杀=银白，烈火逐日=金橙）
- 🚫 不写"刀光一闪""光刃飞出"

### 6.7 🔴 打击反馈（2026-07-31 导演指定·永久规则）

**打击点持续迸发火星、冲击波，连续打击时屏幕边缘轻微震动。**

**火星+冲击波**（不是一瞬间炸完，是持续迸发）：
```
打击点火星持续迸溅，环形冲击波层层扩散
```

**屏幕边缘震动**（不是全屏剧烈晃，是边缘在抖中心稳）：
```
画面边缘轻微震动
```

**三者的搭配关系**：
| 场景 | 火星 | 冲击波 | 边缘震动 |
|------|------|--------|---------|
| 单刀刺杀命中 | ✅ 持续迸溅 | ✅ 环形扩散 | ✅ |
| 连续出刀压制 | ✅ 逐刀累计 | ✅ 层层叠加 | ✅ 逐刀增强 |
| 双烈火终结 | ✅ 爆发性喷溅 | ✅ 大范围扩散 | ✅ 最强震动 |
| 绕圈走位 | ❌ | ❌ | ❌ |
| 战后留白 | ❌ | ❌ | ❌ |

## 九、传奇打斗提示词落笔示例

### 9.1 单镜落笔模板（新规范集成）

```
景别：FS全景
角度：斜侧俯拍，机位侧上方约35°
镜头：固定
内容：秦画左前景距BOSS一米，晚晴画右上方后景三米。秦右手刀斜挑——刀尖拉出银白长条形刀芒，多层运动拖影沿刀锋轨迹展开——隔空贯穿BOSS胸口。打击点火星持续迸溅，环形冲击波层层扩散。画面边缘轻微震动。秦碎步后退从前景退向远处→BOSS转身追→晚晴从右上方后景斜插切入中景隔位停住。
```

### 9.2 刀芒+打击反馈嵌入规则

**不另起字段、不加多余描述，每条规范嵌在对应的动作节点后面：**

| 动作节点 | 嵌入内容 |
|---------|---------|
| 出刀动作 | `刀尖拉出[银白/金色]长条形刀芒，多层运动拖影沿刀锋轨迹展开` |
| 命中瞬间 | `打击点火星持续迸溅，环形冲击波层层扩散` |
| 连续出刀 | `画面边缘轻微震动`（每刀追加，逐刀增强） |
| 拉扯换位 | `从[前/后]景[退/切入]到[远处/近处]`，纵深位移写法 |

### 9.3 三机位落笔规则

| 机位 | 落笔 | 适配 |
|------|------|------|
| **斜侧45°俯拍**（默认） | `角度：斜侧俯拍，机位侧上方约45°` | 走位对峙/刺杀/烈火/开天斩/逐日 |
| **纯侧面** | `角度：侧面平拍` | 野蛮冲撞/冲锋等长位移技能 |
| **后背俯视角** | `角度：后背俯拍，机位在人物后上方` | 双烈火终结/龙影/大招爆发 |

- 一段内可切换机位，不锁死一个角度
- 站位写法：斜侧俯拍用`画左前景`/`画右上方后景`交代纵深；纯侧面用`画左`/`画右`；后背俯视用`正前方`/`远处`
