# 小说转剧本

把小说文本转换为标准剧本格式，同时提取资产表。

## 两阶段转换流程

### Stage 1：小说文体过滤

小说文本包含大量不适合剧本的元素，转换时必须过滤：

**去掉：**
- 内心独白（"他心想"、"她感到"）
- 作者评论和旁白
- 时间跳跃的抽象描述（"多年以后"、"转眼间"）
- 人物心理活动（"他很愤怒"、"她失望极了"）

**保留：**
- 可观察的动作（身体行为、表情变化）
- 可听见的对话（角色说的话）
- 场景和环境的物理描述
- 物品和道具的使用

### Stage 2：剧本格式组织

按标准剧本格式输出：

```
SCENE HEADING（场景头）
INT./EXT. 地点 - 时间

ACTION（动作）
大写描写，只写观众能看到的。

CHARACTER（角色）
DIALOGUE（对话）
```

## 资产提取

转换同时提取资产表：

## 使用方法

1. 接收导演提供的小说文本
2. 按 Stage 1 过滤非剧本元素
3. 按 Stage 2 组织为剧本格式
4. 同时输出资产提取表
