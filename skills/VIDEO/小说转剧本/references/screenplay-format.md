# 剧本格式标准

## 场景头（Scene Heading）

格式：`INT./EXT. 地点 - 时间`

- INT. = 室内（Interior）
- EXT. = 室外（Exterior）
- 半室内半室外用 `INT./EXT.`
- 时间：DAY / NIGHT / DAWN / DUSK / CONTINUOUS

示例：
```
INT. 酒馆 - DAY
EXT. 城镇街道 - NIGHT
INT./EXT. 马车内 - DAY
```

## 动作（Action）

- 全大写
- Present tense（现在时）
- 只写观众能看到和听到的
- 每段不超过3-4行
- 首次出场的角色名大写

示例：
```
The tavern is crowded. ALaric stands by the bar, scanning the room. He notices a hooded figure in the corner.

SARAH enters through the front door. She looks around nervously.
```

## 角色名（Character）与对话（Dialogue）

- 角色名居中，大写
- 对话缩进在角色名下方
- 可加情绪标注（括号内，小写）

示例：
```
SARAH
(whispering)
Is anyone here?

LARIC
(calm)
You're not alone.
```

## 括号标注（Parenthetical）

用于动作/情绪同时发生：

```
LARIC
(grabbing her arm)
Stay down.
```

## 特殊格式

### 音效/特效（可大写）

```
*SOUND: 远处雷声*
*EFFECT: 剑身泛起蓝光*
```

### 镜头指示（可选）

```
CUT TO:
FADE IN:
```

# 小说转剧本转换规则

## 必须转换

| 小说写法 | 剧本写法 |
|---------|---------|
| "他愤怒地站起来" | HE stands abruptly, jaw clenched. |
| "她心里很难过" | She looks down, eyes glistening. |
| "多年以后..." | 删掉或转为场景描写 |
| "他拿起那把剑" | HE picks up the sword. |
| "只见..." | 直接描写场景 |

## 常用动词转换

| 含义 | 剧本动词 |
|-----|---------|
| 生气 | slams, snaps, glares |
| 高兴 | smiles, laughs, brightens |
| 悲伤 | looks down, voice breaks, eyes glisten |
| 思考 | pause, eyes narrow, glances at |
| 害怕 | steps back, voice trembles, grips |

## 场景拆分

一段小说描写可能包含多个场景，需拆分：

- 地点变化 → 新场景头
- 时间跳跃 → 新场景头
- 视角切换 → 新场景头
