# 景别/角度/运镜速查

## 景别选择决策树

```
场景建立？
├── 是 → Wide Shot / Extreme Wide Shot
└── 否
    ├── 两人以上对话？
    │   ├── 是 → Over-the-Shoulder / Medium Shot
    │   └── 否 → 单人？
    │       ├── 是
    │       │   ├── 表情/情绪 → Close-Up / Extreme Close-Up
    │       │   ├── 动作/肢体 → Medium Shot / Full Shot
    │       │   └── 身份建立 → Medium Shot（含道具）
    │       └── 否 → 两人关系镜头
    └── 动作场景？
        ├── 是 → Medium Wide Shot + 跟拍
        └── 否 → Medium Shot
```

## 角度选择原则

| 角度 | 适用场景 | 效果 |
|-----|---------|------|
| Eye Level | 对话、日常 | 客观、中性、亲近 |
| Low Angle | 角色登场、权威、力量 | 仰视、威严、压迫感 |
| High Angle | 弱势角色、俯瞰场景 | 俯视、脆弱、无力 |
| Bird's Eye | 建立镜头、位置关系 | 全景、地图感 |
| Dutch Tilt | 紧张、醉酒、混乱 | 不稳定、焦虑 |

## 运镜选择原则

| 运镜 | 适用场景 | 效果 |
|-----|---------|------|
| 固定 | 文戏、对话、静态场景 | 稳定、专注表演 |
| 推 | 聚焦、强调、紧张感 | 接近、专注 |
| 拉 | 揭示、退出、情绪释放 | 远离、开放 |
| 跟拍 | 运动主体、行进 | 临场感、跟随 |
| 手持 | 动作、追逐、真实感 | 呼吸感、紧张 |
| 环绕 | 角色内心、紧张对峙 | 压迫、聚焦 |
| 俯仰 | 情绪变化、视角切换 | 节奏、过渡 |

## 场景类型 → 景别/运镜速查

| 场景类型 | 起始景别 | 典型景别 | 典型运镜 |
|---------|---------|---------|---------|
| 场景建立 | EWS/WS | WS | 固定或缓慢推 |
| 对话(两人) | MS | MS/OTS | 轻微摇或固定 |
| 对话(多人) | WS | MS/CU | 切换 |
| 动作/打斗 | WS/MS | MS/CU | 手持+跟拍 |
| 追逐 | WS | WS/MS | 跟拍+手持 |
| 独白/思考 | MCU | CU/ECU | 固定或缓慢推 |
| 紧张/恐怖 | WS | CU | 手持+固定 |
| 战斗高潮 | WS | MS/ECU | 手持+快速切换 |

## 景别与信息密度

| 景别 | 可见信息量 | 适用内容 |
|-----|-----------|---------|
| EWS | 全场景+环境 | 建立、地点 |
| WS | 全身+环境 | 动作、位置 |
| MS | 膝盖以上 | 对话、关系 |
| MCU | 胸部以上 | 交流、表情 |
| CU | 肩以上 | 表情、细节 |
| ECU | 局部特写 | 情绪、道具 |

## 连戏检查

同一场景连续镜头时：
1. 角度变化不超过30度（避免跳变）
2. 景别跳变要有叙事目的
3. 保持轴线一致（180度规则）
4. 运动方向保持一致
