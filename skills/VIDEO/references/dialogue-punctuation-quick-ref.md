# 台词标点符号·语气控制速查表

> 来源：人物表演管理技能 §五
> 触发：所有含台词的提示词出稿前，必须过本表

## 一、标点→语气对应规则

| 标点 | AI语音效果 | 场景 | 示例 |
|------|-----------|------|------|
| `？` | 末字自动上扬 | 疑问/质问 | `你也知道自己很没用？` |
| `！` | 音量↑+语速↑+强度↑ | 爆发/命令/嘲讽 | `给我滚！` |
| `……` | 声断气连·渐弱 | 犹豫/哽咽/被打断/悬念 | `152级了……` |
| `——` | 停顿+悬停 | 转折/话没说完 | `等等——你说什么？` |
| `，` | 短停+抬升（话没完） | 连说/并列 | `装备可以换，但……` |
| `。` | 降调+停顿 | 陈述收束 | `这是我的答案。` |
| `~` | 尾音上扬+声线变软 | 调侃/撒娇/暧昧 | `讨厌~` |

> ⚠️ 全角中文标点（！？，。……——）是唯一安全协议。

## 二、台词+语气组合写法

### 标准格式
```
`台词内容。` + 说法动词 + 表情动作描写
```

### 示例
```
`你也知道自己很没用？` 冷声质问，眉头内侧下压并聚拢
`哈哈哈……` 狞笑，声断气连渐弱
`152级了……` 俯视，语气拖长悬念停顿
`比我想象的快点` 画外音，轻蔑嘲讽
`一大陆的顶级强者，现在穿着……` 俯视，语气平稳带审视
`新手村的破烂？` 画外音上扬
`装备可以换。但战斗的意识……不会消失！` 坚定，从牙缝挤出
```

## 三、禁止事项

- ❌ `说："台词"` → 用说法动词替代"说"
- ❌ `笑着说` → 改用嘴角弧度+眼角描写
- ❌ 大情绪词（愤怒/开心/悲伤）→ 改用肌肉动作翻译
- ❌ 语速参数（5字/秒）→ AI视频模型不识别
- ❌ 同一镜内写嘴唇动作+台词 → 冲突

## 四、出稿前强制检查

1. 台词后有标点吗？（？/！/……/。/，/——）
2. 说法动词是动作驱动吗？（质问/冷笑/嘶哑/低声道，不是"说"）
3. 表情是肌肉动作翻译吗？（不是大情绪词）
4. 语气和情绪匹配吗？（克制用……/爆发用！）

## 五、常用说法动词速查

| 语境 | 推荐动词 |
|------|---------|
| 轻蔑/嘲讽 | 冷哼、狞笑、嗤笑 |
| 质问 | 质问、逼问、冷声 |
| 坚定 | 从牙缝挤出、一字一顿 |
| 愤怒爆发 | 怒吼、暴喝、咆哮 |
| 犹豫/哽咽 | 声音发颤、喉头哽住 |
| 平静陈述 | 沉声道、冷淡 |
| 画外音 | 仅标注`画外音`，不写说法动词 |
