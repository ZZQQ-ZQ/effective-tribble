## 第七集《太渊征战》打斗设计

### BOSS虚闪设计（参考牛头一护）
- **蓄力位置**：两只牛角之间，不是手掌
- **光团形态**：气流状汇聚，紫红光团，像气流不像固体
- **蓄力过程**：慢慢壮大

## 🔴 导演强调的规则（2026-08-06 新增·永久记忆）

### 1. 近身缠斗 vs 远程施放技能
- **近身缠斗**：两人贴身近战，刀剑相接，拳脚来往 → 块1加"打击瞬间自带顿帧和镜头震动...连续动力链"
- **远程施放技能**：两人保持距离各自站在位置发招 → 块1不加那段

### 2. 色彩与影调不加打斗特效
- 色彩与影调 = 块1影视风格色调调色描述 + 氛围 + 天气 + 环境生命力
- 不写"金色剑光与银白龙影对冲"等打斗特效颜色

### 3. 主体只写名字
- 主体直接写角色名，不写装备描述，不加图ID

### 4. 技能冲向画外不加BOSS
- 镜2、3人物在画边缘，技能冲向画外，不带BOSS入画，避免模型空间混乱
- 镜4才拍BOSS全景，技能攻入画面
