### 教训2：别在导演没说"出"时抢发（14:06）
- 导演说"剑有参考图别加名字"——我当成出稿指令，直接发完整提示词
- 实际上导演只是在纠正细节，没喊出
- 规则1再次确认：不含「发」「出」「写吧」「来吧」「重出」→不输出任何提示词

### 教训3：记信息不要越记越缩（14:03 导演指出）
- 每次复述分镜内容会不自觉地精简描述
- 导演说"你每次记东西就越记越少，到最后都不对了"
- 对策：锁死原文不压缩，复述时照抄不简化

### 教训4：5个3≠我在笑你（14:09）

### 核心提炼原理

| 原理 | 本质 |
|------|------|
| 注意力即预算 | 每个词争抢有限影响力。早写>后写。废话不只是难看——它花钱。 |
| 没有NOT | 否定=弱语法包着强激活。"no blood"仍激活blood概念 |
| 时间轨迹先验 | 模型偏好平滑因果运动。一个物理原因+可见后果>五个舞台指示 |
| 错误复利 | 每帧受邻居影响重合成。身份误差跨片段累积。第五代必崩。 |
| 参考图压文本 | 图比段落携带更多信息。文本重描述参考图=第二条矛盾指令 |
| 细节能力=面积 | 占画面2%的脸=2%空间表征。远脸/小手/小logo最先崩 |
| 音画联合生成 | 每多一个头部动作就压缩唇形同步精度 |
| 一镜一意图 | 所有乐器弹同一个音。每次选都能答"因为这个意图是X" |
| 快=降质 | "fast"触发插帧→模糊/鬼影→慢动作代偿 |
