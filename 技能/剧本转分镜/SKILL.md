# 剧本转分镜

把剧本格式文本转换为分镜脚本。

## 输入格式

剧本格式（来自「小说转剧本」技能）：
```
SCENE HEADING
INT./EXT. 地点 - 时间

ACTION
大写描写，只写观众能看到的。

CHARACTER
DIALOGUE
```

## 输出格式

分镜脚本（Format B 五字段）：
```
镜头X（X-X秒）：
景别：
构图：
运镜手法：
画面内动：[描述]
[台词]（如有）
```

## 转换流程

### Step 1：场景拆分

一个剧本场景可能包含多个镜头，按动作节拍拆分：

- 角色进入/离开 → 新镜头
- 视角切换 → 新镜头
- 动作变化 → 新镜头
- 对话切换 → 新镜头或保持

### Step 2：景别分配

按场景内容选择景别：

- 场景介绍/大动作 → Wide Shot / Wide
- 角色关系/对话 → Medium Shot / Medium
- 表情/细节 → Close-Up / CU
- 情绪特写 → Extreme Close-Up / ECU

详见 references/shot-size-guide.md

### Step 3：角度与运镜

按叙事目的选择角度和运镜：

- 建立场景 → Eye Level / 固定
- 对话 → OTS / 轻微摇镜
- 动作 → 低角度 / 手持跟拍
- 紧张感 → 高角度 / 手持

详见 references/shot-size-guide.md

### Step 4：时长估算

- 对白：按语速估算（正常对话3-4字/秒）
- 动作：按动作复杂度估算（1-3秒）
- 场景建立：2-4秒
- 过渡镜头：1-2秒

## 输出检查

生成分镜后检查：
1. 场景内动作是否连贯
2. 景别变化是否有叙事目的
3. 时长是否合理
4. 台词是否与剧本一致

## 与视频提示词的区别

分镜脚本 ≠ 视频提示词。

分镜脚本是导演的拍摄计划，用于：
- 向导演展示拍摄思路
- 作为视频提示词的输入

视频提示词需要另外按「视频提示词技能」生成。

## 技能联动矩阵

生成分镜时，根据场景类型触发对应技能：

| 场景类型 | 触发技能 |
|---------|---------|
| 打斗/战斗 | 打斗设计技能 + 动态运镜技能 + 传奇打斗逻辑 |
| 对话/对峙 | 人物表演管理技能 + 镜头逻辑性技能 |
| 动作/运动 | 动态运镜技能 + 场景一致性技能 |
| 远景/场景建立 | 构图技能 + 环境生命力增强技能 |
| 特写/表情 | 真实感增强技能 + 人物表演管理技能 |
| 光效/魔法 | 视觉光效基调技能 + 色彩调色技能 |
| 室内场景 | 场景质感增强技能 + 场景一致性技能 |
| 室外场景 | 环境生命力增强技能 + 色彩调色技能 |

## 输出到视频提示词

分镜脚本完成后，按导演指令转换为视频提示词。此时触发：
1. 提示词规范技能（违禁词审查）
2. 影视风格技能（风格定位）
3. 对应场景类型技能（打斗/对话/动作等）
4. 构图技能 + 运镜技能 + 真实感技能
