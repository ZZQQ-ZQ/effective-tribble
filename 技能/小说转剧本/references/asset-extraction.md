# 资产提取规则

转换小说为剧本时，同步提取资产表。

## 资产类型

### 角色（Cast）

提取所有出现的人物：

```
角色清单：
- LARIC（主角，剑士）
- SARAH（女主角，法师）
- MYSTERIOUS STRANGER（神秘人）
```

提取信息：
- 角色名
- 角色定位（主角/配角/群演）
- 首次出场场景
- 特殊要求（配音/动作替身等）

### 道具（Props）

提取所有被提及的物品：

```
道具清单：
- 古旧长剑（LARIC持有）
- 蓝色魔法书（SARAH持有）
- 木制酒杯（酒馆场景）
```

提取信息：
- 物品名称
- 用途/场景
- 持有人（如有）

### 场景/地点（Locations）

提取所有场景：

```
场景清单：
1. INT. 酒馆 - DAY（场景1-3）
2. EXT. 城镇街道 - NIGHT（场景4-5）
3. INT. 废弃神庙 - DAY（场景6）
```

提取信息：
- 场景头格式
- 场景数量
- 每个场景的剧情功能

### 特殊资产

```
特效：
- 剑身蓝光（场景6）
- 闪电效果（场景4）

音效：
- 雷声（场景4）
- 剑击金属声（战斗场景）
```

## 提取格式

输出时，在剧本正文后附资产表：

```
========== 资产表 ==========

【角色】
1. LARIC - 主角，剑士，场景1-6
2. SARAH - 女主，法师，场景1,3,6
...

【道具】
1. 古旧长剑 - LARIC持有，场景1-6
2. 蓝色魔法书 - SARAH持有，场景3,6
...

【场景】
1. INT. 酒馆 - DAY - 场景1-3
2. EXT. 城镇街道 - NIGHT - 场景4-5
...

【特效/音效】
1. 剑身蓝光 - 场景6
2. 雷声 - 场景4
...
```

## 注意事项

- 群演角色可归类为"侍从A/B"、"卫兵1-3"等
- 一次性道具可不列入（如"桌上的酒杯"）
- 重复出现的道具有则必录
